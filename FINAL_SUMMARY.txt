/**
 * 🛡️  IDEMPOTENCY (Safe to Retry)
 * ════════════════════════════════════════════════════════════════════════
 * 
 * ✓ Create Order Endpoint
 *   └─ Same reference = same order returned
 *   └─ Prevents: Duplicate orders from double-clicks or retries
 * 
 * ✓ Verify Payment Endpoint
 *   └─ Cached via transaction logs
 *   └─ Status check prevents re-verification
 *   └─ Prevents: Duplicate Paystack API calls
 * 
 * ✓ Webhook Processing
 *   └─ Unique eventId deduplication
 *   └─ Won't process same event twice
 *   └─ Prevents: Duplicate order updates from webhook retries
 * 
 * Result: Network failures, timeouts, and retries are SAFE ✓
 */

// HOW THE PAYMENT FLOW WORKS
// ══════════════════════════════════════════════════════════════════════════

/**
 * 🔄 THE COMPLETE FLOW
 * ════════════════════════════════════════════════════════════════════════
 * 
 * 1️⃣ CUSTOMER FILLS FORM (Frontend)
 *    └─ Name, email, phone
 * 
 * 2️⃣ CREATE ORDER (Frontend → Backend)
 *    POST /api/orders/create
 *    ├─ Backend creates order
 *    ├─ Returns: orderId, reference, amount
 *    └─ Status: pending
 * 
 * 3️⃣ SHOW PAYSTACK MODAL (Frontend)
 *    └─ Customer enters card details
 * 
 * 4️⃣ PROCESS PAYMENT (Paystack)
 *    ├─ Validates card
 *    ├─ Processes charge
 *    └─ Sends TWO responses:
 *       ├─ To frontend: payment success
 *       └─ To backend: webhook (async)
 * 
 * 5️⃣ VERIFY PAYMENT (Frontend → Backend)
 *    POST /api/orders/verify
 *    ├─ Confirms with Paystack API
 *    ├─ Updates order status: paid
 *    └─ Returns: success
 * 
 * 6️⃣ SHOW SUCCESS PAGE (Frontend)
 *    └─ Customer confirms payment
 * 
 * 7️⃣ WEBHOOK SAFETY NET (Backend)
 *    POST /paystack/webhook
 *    ├─ Arrives async from Paystack
 *    ├─ Double-checks order is paid
 *    └─ Logs for audit trail
 * 
 * FINAL STATE: Order marked as "paid" in database ✓
 */
